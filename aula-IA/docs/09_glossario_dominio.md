# Glossário de domínio

## 1. Termos do negócio
- **Receita**: Qualquer entrada de dinheiro (ex: salário, rendimentos). Sinônimos proibidos: lucro, ganho.
- **Despesa**: Qualquer saída de dinheiro ou gasto. Sinônimos proibidos: custo, perda.
- **Categoria**: Agrupamento lógico de receitas ou despesas para fins de organização (ex: Alimentação, Transporte, Moradia).
- **Extrato**: Listagem cronológica de todas as transações financeiras dentro de um período específico.

## 2. Termos técnicos
- **Clean Architecture**: Padrão arquitetural focado na separação de responsabilidades em camadas, garantindo independência de frameworks e banco de dados.
- **DDD (Domain-Driven Design)**: Abordagem de modelagem de software cujo foco está no domínio central e na lógica do negócio.
- **App Mobile**: O aplicativo cliente que será instalado no dispositivo do usuário final.
- **Transação**: Registro único na base de dados que representa a efetivação de uma Receita ou de uma Despesa.

## 3. Convenções de nomenclatura
- Nomes de entidades no banco de dados devem estar no plural (ex: `usuarios`, `transacoes`).
- Endpoints da API devem seguir o padrão REST utilizando o plural (ex: `/api/v1/despesas`).
